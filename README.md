# signals-generator-app
Приложение WPF

## Назначение
Приложение WPF для генерации сигналов (синусоида, прямая, белый шум), их отображения в виде графиков и обработки: суммирование, склейка, фильтрация, поиск выходов за допустимый диапазон, поиск пересечений заданного порога с отметками на графике и списком найденных пересечений, сохранение и загрузка сигналов и разметки.

Вся предметная логика вынесена в библиотеку SignalProcessing.Core из репозитория signals-core.

## Состав репозитория
- `SignalGenerator.sln` – решение приложения (включает проект библиотеки из соседнего репозитория)
- `SignalGenerator.App` – проект приложения WPF

## Требования
- .NET Framework 4.8
- ScottPlot.WPF 5.1.57 (пакет NuGet)
- Visual Studio 2022 или новее

## Связанные репозитории
Приложение использует библиотеку из репозитория
https://github.com/blzxc/signals-core

Оба репозитория клонируются в один родительский каталог, рядом друг с другом, под своими именами:

```
C:\talanov\
├── signals-core\
└── signals-generator-app\
```

Решение SignalGenerator.sln ссылается на проект библиотеки
по относительному пути ..\signals-core\SignalProcessing.Core\,
поэтому имена каталогов и их расположение изменять нельзя: при ином расположении или переименовании каталогов решение не откроется.
